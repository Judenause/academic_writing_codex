# Model Paper Patterns

Use these drafting patterns when the user asks for new prose rather than revision only.

## Abstract Pattern

1. Problem context and concrete limitation.
2. Proposed idea and mechanism.
3. Main evaluation scope.
4. Main result with bounded wording.
5. Practical implication or takeaway.

## Introduction Pattern

1. Why the problem matters now.
2. Why the existing baseline or prior line of work falls short.
3. What exact gap remains.
4. What the proposed method changes.
5. What evidence is available and how the paper is organized.

## Related Work Pattern

1. Group prior work by problem-solving strategy, not by citation order alone.
2. Explain the strength of each group.
3. State the limitation that matters for the current paper.
4. Transition directly into the need for the present method.

## Contribution Pattern

Each contribution should name:

1. The specific problem or limitation.
2. The mechanism introduced to address it.
3. The evidence or validation boundary.

Avoid contribution bullets that claim novelty or impact without tying the claim to a concrete technical gap.

## Conclusion Pattern

1. Restate the problem and contribution in narrower terms than the introduction.
2. Summarize the evidence, not only the claim.
3. State the practical implication under the validated conditions.
4. Keep future work bounded by what the current implementation did not test.
